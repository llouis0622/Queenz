# Queenz 👑

링크드인 **Queens** 스타일 퍼즐을 둘이서 즐기는 PWA. 안드로이드 크롬에서 홈 화면에 추가하면 앱처럼 실행되고, 오프라인에서도 동작해요.

- **500단계**: 5×5부터 11×11까지 점진적 난이도, 모두 유일해가 보장된 퍼즐
- **프로필 2개**: 각자 자기 폰에서 진행, 홈 화면에서 클리어 수·별·시간·실패 횟수 비교
- **목숨 3개**: 규칙 위반 퀸을 놓는 즉시 -1, 모두 잃으면 재도전
- 되돌리기, 힌트(별 감소), 다시 시작, 자동 ✕ 표시, 드래그로 ✕ 표시
- 화이트/다크 테마, 서비스 워커 오프라인 캐시, 자동 업데이트 안내

## 규칙

각 **행**, **열**, **색 영역**에 퀸을 정확히 하나씩 놓으세요. 퀸끼리는 **대각선을 포함해 서로 붙을 수 없어요**.

- 탭: 빈칸 → ✕ → 👑 → 빈칸
- 드래그: 여러 칸에 ✕ 표시(또는 ✕ 해제)
- 별: 실수 0·힌트 0 = ★★★, 실수 ≤1·힌트 ≤1 = ★★, 그 외 ★

## 배포 (GitHub Pages)

1. 이 저장소의 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 설정 (최초 1회)
2. `main`(또는 `master`) 브랜치에 푸시하면 `.github/workflows/deploy.yml` 이 자동 배포
   - 다른 브랜치가 기본 브랜치라면 **Actions → Deploy to GitHub Pages → Run workflow** 로 수동 실행 가능
3. 주소: `https://llouis0622.github.io/Queenz/`

## 안드로이드에 설치

1. 크롬으로 배포 주소 열기
2. 메뉴(⋮) → **홈 화면에 추가** (또는 하단에 뜨는 "설치" 배너)
3. 홈 화면 아이콘으로 실행하면 전체 화면 앱처럼 동작

기록은 각 기기의 브라우저 저장소(localStorage)에 저장돼요. 두 사람이 각자 자기 폰에서 같은 프로필 번호를 골라 쓰면 됩니다.

## 개발

```bash
npm run dev        # http://localhost:5173 로컬 서버 (의존성 없음)
npm test           # 엔진 단위 테스트 + 500단계 전수 클리어 검증
npm run validate   # data/puzzles.json 무결성(연결성·유일해) 검증
npm run generate   # 퍼즐 재생성 (시드 고정, 결정적)
npm run icons      # PNG 아이콘 재생성
```

퍼즐 생성 방식: 규칙을 만족하는 퀸 배치를 무작위로 만들고 → 각 퀸을 씨앗으로 영역을 확장 → 해가 둘 이상이면 다른 해의 퀸 칸을 이웃 영역으로 옮겨 모호성을 제거 → 유일해가 될 때까지 반복. 같은 크기 안에서는 탐색 노드 수 순으로 정렬해 난이도가 점점 올라갑니다.

## 구조

```
index.html            앱 셸
css/style.css         테마 토큰(라이트/다크), 보드, 화면 스타일
js/app.js             화면·라우팅·입력·모달·서비스 워커 등록
js/engine.js          보드 규칙 엔진(순수 로직)
js/store.js           localStorage 프로필/진행/설정
data/puzzles.json     500단계 퍼즐 데이터
sw.js                 서비스 워커 (앱 셸 사전 캐시)
manifest.webmanifest  PWA 매니페스트
scripts/              생성기·검증기·아이콘·개발 서버
tests/                엔진 테스트
```
